## Architecture

React + TypeScript + Vite frontend, with GSAP/Motion animation and CSS/Tailwind styling. Production serves compiled static files through Nginx in Docker. Local deployment uses port 8080. A separate legacy HTML application is served at /catalog/.

There is no first-party backend API, database, authentication server, payment handler, order-creation endpoint or server-side upload handler implemented in this repository.

src/App.tsx selects the main archive or catalog view. src/components/BLineCatalogSection.tsx owns the active React catalog. src/data/catalogTaxonomy.ts parses and builds hash routes. nginx.conf controls static delivery and SPA fallback.

## Routes

Fragments beginning with # are browser state, not HTTP API paths.

- / or /#archive: home aliases.
- /#catalog: recipient catalog.
- /#catalog/category: category index.
- /#catalog/category/:category: category listing.
- /#catalog/category/:category/:family: family listing.
- /#catalog/theme/:theme: theme listing.
- /#catalog/tier/:tier: tier listing.
- /#catalog/occasion/:occasion: occasion listing.
- /#catalog/kind/:kind: item-kind listing.
- /#catalog/item/:code: product detail modal.
- /#catalog/bundle: bundle builder.
- /#catalog/bundle/:template: package template.
- /#bline: partner collection.
- /#bline/item/:code: partner detail modal.
- /catalog/: independent legacy catalog; NOT an alias of /#catalog.

Hash query controls include view=grid|list|index, q, supplier=1, 3d=1, priced=1, kind, contains, recipient, occasion, tier, qty and g (encoded bundle groups). Valid values depend on the catalog data.

Operator flag ?dev=1 belongs before the hash. It reveals local authoring tools and is not authentication. Preview parameters such as ?v=5.2 do not define another application route.

Static media includes /logo-smg.jpg, /assets/videos/*, /assets/smartgift/plates/*, mockups/*, 3d/*.glb, story/* and /catalog/assets/*. Image, video, font and JavaScript URLs are not business APIs. A 200 HTML response at an arbitrary path may be SPA fallback, not an implemented endpoint.

## Brief API and handoff

Implementation: src/data/briefSubmit.ts, src/config/briefConfig.ts and src/components/BriefSubmitPanel.tsx.

- Optional POST target: build-time VITE_BRIEF_ENDPOINT; this repository does not host the receiver.
- Content-Type: application/json.
- Contract: smartgift-brief/1.
- Payload: schema, submitted_at, source, page_url, brief, lines, optional bundle, optional contact and notes.
- Brief fields: recipient, occasion, tier, qty.
- Contact fields: name, company, email, phone, note. Form requires a name and email or phone.
- Timeout: 8 seconds. HTTP non-2xx/network failures trigger fallback.
- Success is based on response.ok; no structured response body is consumed.
- Fallback order: webhook, configured VITE_SALES_EMAIL mailto, then clipboard.
- Optional VITE_LINE_OA_URL provides a continuation link, not a LINE messaging API.

Configuration snapshot on 2026-09-10: local webhook URL unset, sales email configured, LINE OA URL unset. Recheck before describing deployed connectivity. No CRM delivery was tested by the inventory audit.

Opening an email draft or copying text is not proof of delivery. Reference totals are not confirmed orders. Contact data is not persisted by this application in localStorage or a database. Do not submit test customer messages without authorization.

## Product and brand boundaries

- SmartGift focuses on corporate gifting, recipient needs and meaningful customization.
- Reach, Select, Signature and Bespoke are gift-treatment tiers, not product categories.
- B-Line items are partner design pieces, not SmartGift-manufactured products.
- Client mockups and generated plates are design references, not proof of delivered customer orders.
- Draft 3D models must not be represented as measured or approved production CAD.
- Use source-backed product facts and reference prices; do not invent specifications, delivery claims or logos.
- Generated catalog files derive from the sibling business-01-smart-gift data pipeline. Do not hand-edit generated product facts.
- Current home has seven product images and three chapters: BESPOKE, EVERYDAY, ELEVATED, and THE ART OF GIVING.
- Hero v5 uses the same closed-box master for both variants, fixed camera/scale, and linear hinged opening. Preserve the approved mobile white studio background.

## Browser state and external resources

- smg_media_config: per-browser media overrides in localStorage.
- smg_dev: operator visibility preference in localStorage.
- sg-palette: legacy catalog palette preference in localStorage.
- Catalog filters and brief selections: hash state.
- Media file selection creates browser object URLs; it does not upload or publish files.
- Presentation resources include Google Fonts, Google-hosted model-viewer and partner imagery from Higgs/CloudFront.
- Tailscale Funnel is deployment transport, not an application API. Recheck its current configuration before sharing a URL. Other services on the same host are outside this inventory.
